# LIBRARY MANAGEMENT SYSTEM
**Author:** Remofilwe Molehabangwe
**Cohort:** Data Science Practitioner 2026 - Melsoft Academy

## Description
A console library system that searches for the catalogue of books and a register of members, where members borrow and return books under real rules.

## How to run
python library.py

## Features
1. Add a book
2. Register a member
3. Borrow a book
4. Return a book
5. Search the catalogue
6. Member summary
7. Library report
8. Exit
